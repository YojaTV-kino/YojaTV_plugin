# Untitled Plugin — YojaTV para Kino TV

Plugin de catálogo y reproducción de anime en español latino y subtitulado para la aplicación **Kino TV**, impulsado por el catálogo de JKAnime.

## Autores

- **JuandreXter**
- **YojanderGaming**
- **einer_bg**

---

## Características

- 🎬 **Catálogo e Inicio**: Muestra los últimos episodios y las series populares.
- 🔍 **Búsqueda e Historial**: Búsqueda directa de series de anime.
- 📺 **Episodios y Servidores**: Decodificación directa de enlaces de reproductores (VOE, Streamtape, MP4Upload, Mega, MediaFire, etc.).
- ⬇️ **Descargas para ver sin conexión**: Habilitado mediante la capacidad nativa de descargas de Kino.
- 🔑 **Plugin Firmado Ed25519**: Autenticidad verificada para actualizaciones seguras.

## Pasos para publicar en GitHub

1. Crea un repositorio público en GitHub (NUNCA un fork) llamado:
   `YojaTV-For-KinoTV` bajo la cuenta `RY456`.
2. Sube todos los archivos del proyecto a la raíz del repositorio (`kino-plugin.json`, `plugin.js`, `icon.png`, `README.md`).
   - ⚠️ **IMPORTANTE**: El archivo `kino-author-key.pem` NO se sube jamás a GitHub (está ignorado por `.gitignore`).
3. Agrega la etiqueta (topic) `kino-plugin` en GitHub:
   - Ve a tu repositorio en GitHub -> **About** -> icono ⚙️ (Editar).
   - En **Topics**, escribe `kino-plugin` y presiona **Save changes**.

## Cómo instalar en Kino TV

### En el celular / tablet:
1. Abre Kino TV.
2. Abre el menú lateral ☰ -> **Plugins**.
3. Presiona el botón **+**.
4. Escribe: `RY456/YojaTV-For-KinoTV` y presiona **Agregar**.

### En el Android TV / Smart TV:
1. Abre Kino TV.
2. Ve a **Ajustes** -> **Plugins**.
3. Selecciona **Agregar**.
4. Escribe: `RY456/YojaTV-For-KinoTV` y confirma.
